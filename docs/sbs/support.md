# SBS support

SBS — Side by Side Pours records two to four pours at once, one coffee
scale each, and shows how closely they match.

## How to use

1. **Connect your scales.** Tap Scale A, then Scale B, and pick each
   scale. C and D are optional. SBS reconnects them next time.
2. **Tare and reset all.** Put your vessels on the scales, then tap
   Tare and reset all.
3. **Start each pour.** Press a scale's timer button as you start
   pouring on it. Every curve starts at its own zero, so the next pour
   can start a few seconds later.
4. **Stop and compare.** Tap Stop to see how closely each pour matched
   scale A, and export the run as CSV.

No scales yet? Tap the **?** button, then **Try with demo scales**.

## Supported scales

- **Bookoo** (Themis Mini and Ultra): fully supported.
- **Beta:** Acaia (Lunar, Pearl, Pyxis), Felicita (Arc, Incline,
  Parallel), Decent Scale, Varia AKU, DiFluid Microbalance. These are
  built from published protocols but not yet tested on real scales.
  If one misbehaves, please report it.

## Troubleshooting

- **A scale doesn't show up:** turn it on, keep it close, and check that
  Bluetooth is allowed for SBS in Settings.
- **A tap or bump shows on the curve:** SBS smooths out taps that come
  back down within a second. Leaning on a scale for longer is kept.
